`onTaskUpdate` call falsely times out. Local direction: dated source read 2026-08-06 of
`node_modules/vitest/dist/chunks/rpc.-pEldfrD.js:48-53` (the error's construction site,

direction: issue #8164's identical analysis, reached independently. **The fix:** PR
#8297, "Prevent rpc timeout on slow thread blocking synchronous methods" (AriPerkkio,
merged by sheremet-va 2025-07-22), sets worker-side birpc `timeout: -1` — shipped in
v4.0.0-beta.4 and the v4.0.0 stable line. **Upstream pages read 2026-08-06 by CC;
independently verified 2026-08-06 by the adjudicator on every checkable point (his
message body: PR title/authors, ship vehicle, #8164's mechanism match, and the
maintainer-adjacent fixed-in confirmation).** GitHub's own pages are the authoritative
endpoint for GitHub-hosted sources — page-level reads, not relays (source-versus-copies,
