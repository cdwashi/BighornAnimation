# Deep Research Prompt — O5 Publication-Grade Re-Sourcing

**Prompt ID:** O5-RESOURCE
**Gates:** v1 exit. Publication-grade sourcing is v1-blocking (Chuck, 07-22).
**Precedent:** D16 — weak citations are recorded faithfully rather than laundered. This task closes them.

---

## Role and objective

You are a research analyst performing **citation verification and upgrade** for a historical simulation that expects academic audit. This is not a request for new findings. It is a request to establish, for each claim below, whether a **publication-grade source** supports it — and to say plainly when one does not.

A publication-grade source is a peer-reviewed work, a scholarly monograph, an archaeological site report, or a contemporary primary document. Wikipedia, popular-history websites, forum posts, marker databases, and relayed summaries are **not** publication-grade, however accurate they may turn out to be.

**The success condition is an accurate verdict, not an upgrade.** "This claim rests only on tier-5 material and no scholarly source supports it" is a complete and valuable answer. Do not manufacture a citation to fill a slot, and do not upgrade a source by finding a scholarly work that says something *adjacent* to the claim.

## The three failure modes to avoid

1. **Citation laundering** — attaching a respectable source to a claim it does not actually make. Before citing, confirm the source asserts *this* claim, not a neighbouring one.
2. **Relay citation** — citing a work you have not consulted because another source cites it. If you have not seen the page, say so; mark it `RELAYED` and name the intermediary.
3. **Precision inflation** — reporting a figure more precisely than the source gives it. If the source says "several hundred," do not report 300.

## Output format

Markdown. One row per claim.

| claim id | claim as encoded | current source tier | upgraded source (author, work, page) | verdict | new confidence | notes |
|---|---|---|---|---|---|---|

`verdict` is exactly one of:

- **UPGRADED** — publication-grade source found and consulted; supports the claim as encoded
- **UPGRADED-MODIFIED** — publication-grade source found; supports a *different* value or wording. Give the source's version. Do not reconcile it with the encoded value.
- **CONFIRMED-WEAK** — no publication-grade source found; the claim stands only on low-tier material. Say what the best available source actually is.
- **CONTRADICTED** — publication-grade source contradicts the encoded claim. Give both.
- **RELAYED** — a promising source exists but you could not consult it. Name it, name the intermediary, state where it is held.
- **UNRESOLVED** — could not be determined.

Close with:

1. **Bibliography** of every source consulted, marking each as consulted directly or relayed.
2. **Access register** — sources that would settle open claims but were unavailable, with holding institution.
3. **Closing JSON:** `{ "promptId": "O5-RESOURCE", "counts": { "UPGRADED": n, "UPGRADED-MODIFIED": n, "CONFIRMED-WEAK": n, "CONTRADICTED": n, "RELAYED": n, "UNRESOLVED": n }, "blockingGaps": [""] }`

## Standing instructions

- Do not average competing figures. Report spreads with a source per bound.
- Do not silently drop a claim you could not verify — it gets a row and a verdict.
- If an upgraded source gives a **different** value than the one encoded, report the source's value. Reconciliation is a ruling for the project owner, not a research decision.
- CONTRADICTED findings are the most valuable output of this task. Lead with them if you find any.
